# Mathis V1.5 — SAV événement

- Libellé client : « Notre technicien Mathis ».
- Mathis accepte désormais un contexte événement et un rôle utilisateur.
- Admin : diagnostic disponible, aucun compte rendu SAV automatique.
- Organisateur / invité : le nom de l'événement est inclus dans le compte rendu lorsqu'il est fourni par le portail.
- Niveau 2 : alerte visuelle SAV + tentative d'alerte sonore.
- Message WhatsApp SAV généré automatiquement et prérempli (envoi manuel via WhatsApp).
- Le rapport rappelle si la prise de photos peut continuer pendant une panne d'impression.
- Préparation d'un son personnalisé : le composant possède la logique de fichier audio ; l'écran de réglage dédié sera à brancher lorsque le portail client utilisera Mathis.
- Pas d'envoi WhatsApp silencieux/automatique sans API WhatsApp Business officielle.
