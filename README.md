# Location Photobooth 28 Suite — V5.1.0

Première vraie base React + Express + PWA.

## Fonctionnalités
- interface noir / or ;
- logo Location Photobooth 28 ;
- connexion administrateur ;
- tableau de bord ;
- base PWA installable ;
- API Express ;
- prêt pour Render.

## Installation locale
```bash
npm install
npm run build
npm start
```

Puis ouvrir http://localhost:3000

## Variables Render
- ADMIN_EMAIL
- ADMIN_PASSWORD
- SESSION_SECRET

## Render
Build Command:
`npm install && npm run build`

Start Command:
`npm start`
